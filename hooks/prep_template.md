# Compact prep

## Goal and next action
One line for the goal. The single next action: edit <path>, run <command>, or ask the user <question>.

## User corrections (verbatim)
Each correction word for word, with its approximate time. A paraphrase is a defect.

## Open standing orders
Each order word for word.

## Decisions with reasons
One line each.

## Live write and data state
Uncommitted changes, files modified, anything half-written.

## Blockers
Open blockers and questions.

## Test status
Last result and the exact rerun command.

## Running subagents
Name, task and state of each running or pending subagent.
